# 株式会社シフト Webサイト（ローカル版）

## プロジェクトの概要

株式会社シフトの会社案内・採用情報を掲載する、1ページ構成のWebサイトです。
パソコンとスマートフォンの画面幅に対応し、ページ内メニュー、募集内容・お問い合わせ案内のポップアップを利用できます。

## 使い方・手動での実行手順

### いちばん簡単な確認方法

`index.html` をダブルクリックすると、ブラウザで表示できます。

### Visual Studio Code / Cursorで確認する方法

Live Server拡張機能をインストールしている場合は、`index.html` を右クリックし、`Open with Live Server` を選択してください。

> Googleマップ、地図リンク、電話リンク、ハローワークへのリンクは外部サービスを利用するため、インターネット接続が必要です。

## 各ファイルの役割

- `index.html`：文章や見出しなど、Webページ全体の構造を定義します。
- `style.css`：色、余白、文字サイズ、スマートフォン表示など、見た目を整えます。
- `script.js`：スマートフォン用メニューとポップアップの開閉を制御します。
- `assets/hero.webp`：ページ上部に表示するメイン画像です。
- `assets/shift-logo.jpeg`：ヘッダーとフッターに表示する会社ロゴです。
- `README.md`：このプロジェクトの概要と実行方法を説明するファイルです。

## 注意事項

- 公開前に会社情報、採用情報、電話番号などが最新か確認してください。
- 画像やロゴを別サイトで公開する場合は、利用権限を確認してください。
- お問い合わせは現在、電話案内のみです。送信フォームやメール送信機能は含まれていません。
